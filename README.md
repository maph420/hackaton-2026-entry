# Cuaderno

Cuaderno es una herramienta pensada para acompañar el estudio de una materia de forma organizada, personalizada y visual. La idea principal es transformar el programa de una asignatura en un recorrido de aprendizaje claro, ayudando a entender qué temas estudiar primero, qué conceptos dependen de otros y cómo avanzar paso a paso.

La app permite crear una materia, subir su programa, agregar materiales de estudio, importar contenido de la FCEIA y mantener un seguimiento del progreso. En lugar de tratar el estudio como una lista larga de temas aislados, Cuaderno lo convierte en un plan estructurado con dependencias y tareas.

## ¿Qué es Cuaderno?

Cuaderno es como un cuaderno inteligente para estudiar. No solo sirve para guardar apuntes o archivos, sino para planificar cómo aprender una materia.

La aplicación ayuda a:

- organizar los temas de una asignatura
- visualizar el orden en que conviene estudiarlos
- marcar qué temas ya fueron comprendidos
- distinguir qué temas dependen de otros
- mantener una biblioteca de materiales para cada curso
- seguir el progreso de forma clara y simple

## ¿Qué problemas resuelve?

Muchas veces los estudiantes reciben un programa con muchísimos temas, pero no saben:

- cuál estudiar primero
- qué temas requieren conocimientos previos
- qué conceptos son más importantes
- qué falta revisar
- dónde encontrar material útil para cada bloque

Cuaderno intenta resolver eso creando un roadmap de estudio: una estructura que guía el aprendizaje y ayuda a ordenar la materia.

## Funcionalidades principales

### 1. Organización por materia
Cada materia tiene su propio espacio dentro de la aplicación. El usuario puede crear una asignatura, ponerle una descripción y mantener todo su contenido separado del resto.

Esto permite tener una biblioteca por curso, con sus materiales, temas y progreso.

### 2. Carga del programa de la materia
La app permite ingresar el programa o contenido curricular de la asignatura. A partir de ahí, se puede construir una base para el estudio.

El programa sirve como punto de partida para:

- definir los temas principales
- estructurar el roadmap
- identificar dependencias entre conceptos
- relacionar materiales con cada bloque

### 3. Agregar materiales de estudio
El usuario puede incluir distintos tipos de contenido, como:

- libros
- apuntes
- guías de estudio
- exámenes anteriores
- material de práctica
- bibliografía
- PDFs o referencias del curso

Esto hace que cada materia tenga una colección de recursos útiles para estudiar cada tema o subtema.

### 4. Importación desde la base de datos de la FCEIA
Una de las funciones más destacadas es la posibilidad de importar contenido desde la base de datos de la FCEIA. Esto permite traer información oficial de la facultad y facilitar la carga inicial de una materia.

La integración puede ayudar a:

- seleccionar una carrera
- elegir una materia
- importar material relacionado
- reutilizar información oficial del programa
- ahorrar trabajo manual en la creación de la materia

Esto hace que el proceso de armar un plan de estudio sea más rápido y completo.

### 5. Roadmap de aprendizaje
Cuaderno genera un mapa de temas y subtemas con dependencias. No es solo una lista de contenido: también muestra cómo se relacionan entre sí.

Por ejemplo, puede indicar que:

- un tema necesita entender otro antes
- algunos conceptos pueden estudiarse en paralelo
- un bloque ya fue finalizado
- todavía falta revisar cierto contenido

Esto facilita el estudio en orden lógico y evita sentir que “todo está mezclado”.

### 6. Marcado de tareas y progreso
La herramienta permite marcar temas, subtemas o actividades como completadas o no completadas.

Esto ayuda al estudiante a:

- ver qué ya aprendió
- mantener un seguimiento real del avance
- identificar gaps o temas pendientes
- sentirse más motivado al ver el progreso

### 7. Práctica y ejercicios
Además de la parte teórica, Cuaderno también contempla la práctica. El sistema puede sugerir o asociar ejercicios y otros materiales de resolución de problemas.

Esto es especialmente útil en materias con fuerte componente práctico o abstracto, como matemáticas, lógica, programación o física.

### 8. Biblioteca personalizada por materia
Cada curso funciona como una biblioteca propia: con teoría, referencias, ejercicios y avance. De esta forma, el estudiante no necesita dispersar la información en distintos archivos o carpetas, sino que tiene todo en un mismo lugar.

## Flujo típico de uso

Un usuario normalmente podría seguir este flujo:

1. Crear una nueva materia.
2. Agregar o importar el programa de la asignatura.
3. Cargar bibliografía y materiales de apoyo.
4. Importar contenido desde la FCEIA si está disponible.
5. Generar el roadmap de temas.
6. Revisar dependencias entre temas.
7. Marcar lo que ya fue completado.
8. Estudiar siguiendo el orden recomendado.
9. Continuar avanzando y actualizar el progreso.

## Tecnologías

El proyecto está desarrollado principalmente con:

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Drizzle ORM
- Better Auth

Estas tecnologías permiten construir una aplicación web moderna, rápida y con buena experiencia de usuario.
